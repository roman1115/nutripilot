# 饮食记录界面重设计与验收

日期：2026-11-13。范围：信息结构、响应式样式及导航，保留完整饮食管理功能。
本次未改数据库、HTTP契约、营养计算、模型调用或保存确认语义，无新增依赖。

## 页面结构

- 四个入口：记录与分析、目标管理、个人食物、数据管理。
- 记录页以四餐记录为主体；桌面右侧显示营养摘要，手机先记录、后营养。
- 日期、日周切换、今天保留在工具栏；今天使用服务端账号时区锚点。
- 草稿默认收起，标记尚未入账；分页未读完显示数量下限，不冒充全部条目数。
- 时区设置、完整度操作、更多营养与计划比较及计划偏差按需展开。
- 目标时间线独立显示，合并重复新增入口；画像中的目标链接直达目标管理。
- 保留完整份量文本、营养依据、模型估算、未知和已知小计语义。

主要实现：`web/src/features/diet/DietView.tsx`、`NutritionOverview.tsx`、
`diet.css`及`web/src/features/profile/ProfileView.tsx`。
实施基线第12节同步更新；工具Schema无变更。
