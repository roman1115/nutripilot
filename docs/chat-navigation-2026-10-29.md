# 对话生成中切换页面不中断

验收日期：2026-10-29，Asia/Shanghai。真实模型最终完成检查时间为 17:44:22。

## 问题与修复

原 `App` 根据当前页面只渲染一个视图。离开对话页时，`ChatView` 被卸载，其清理函数会调用服务端取消接口并中止 SSE；返回时重新从历史恢复，因此可能只看到停止或结束提示。

当前实现将 `ChatView` 保持为应用内容区中位置固定的组件，用 `active` 与原生 `hidden` 控制可见性。其它页面仍按原方式进入和退出：

- 站内切页保留同一会话、请求、消息、草稿及待确认状态；离开期间继续接收最终回答。
- `.chat-layout[hidden]` 明确隐藏聊天区域及其执行面板，避免原 `display: flex` 覆盖原生隐藏规则。
- 后台聊天不执行滚动、会话恢复、历史列表加载和 Esc 键监听；返回后继续正常展示和读取历史。
- 主动停止及真正卸载时的取消逻辑保留。身份失效进入认证页时仍卸载聊天，未绕过现有身份保护。
- 真实验收发现多道菜共享营养来源时会产生重复 React key；来源列表的 key 增加列表位置，保留全部引用与营养值。修复后重新加载并往返页面，无新增控制台异常。

没有引入后台任务队列、服务或新依赖。当前范围是应用内导航；刷新、关闭页面或实际网络断开仍采用现有取消机制。

4. 站内切页没有调用 `/cancel`；点击主动停止恰好调用一次，停止按钮消失并显示停止提示。

模拟请求未提交给模型，不代表真实模型效果。所有网络拦截和临时视窗覆盖已移除；最终页面使用真实服务。
