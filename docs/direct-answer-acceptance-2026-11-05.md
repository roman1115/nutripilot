## 结论与范围

**本轮频繁降级的稳定性样本通过；正文事实和食品安全内容质量未通过。**

主入口18轮自然对话、持久化花生过敏用户4轮，全部正常发布、没有降级、
没有在线全文语义审核，每轮只有1次正文生成。原失败checkpoint等隔离生成9次均发布。
这是有限样本的流程结论，不是准确率，也不是未来绝不降级的保证。

xerina已授权：这轮仍解决不了频繁降级，就向CookHero方案重构。
本次已把普通正文改为“工具事实与必要上下文→一次生成→必要确定性检查→发布”，
移除普通回答发布前的模型审批和数字门禁；没有新增服务或依赖。
当前样本没有触发继续扩大重构的条件。若实际使用仍频繁误拒，继续执行该授权，
不再叠加全文审核、逐句证据契约或反复修订。

## 具体原因与改动

| 位置 | 原问题 | 最终行为 |
| --- | --- | --- |
| `agent/agents/recommendation.py` | 生成、全文模型审核、修订、再审消耗预算，审核也会误判 | 普通正文1次生成；明确结构、对象、来源、安全错误最多修订1次；审核提示只供离线脚本调用 |
| 同上及`agent/answers.py` | 具体做法混入营养映射、旧营养目标和历史助手正文，模型补常见规格 | 共用较短主提示词及现有短任务说明；做法聚焦当前原配方与必要禁忌，不混营养映射或旧正文 |
| `agent/agents/planner.py`、`agent/routing.py` | 做法、营养、通用问答缺少本轮当前画像 | 必须先读取`get_user_profile`；已完成且仅需画像的工具批可直接转生成；画像读取失败保留受控失败 |
| `agent/nodes/tool.py` | 工具规划模型把旧菜的菜籽油、猪肉末擅自列为用户忌口 | 过敏与忌口由当前画像及已确认槽位提供，不接受规划工具参数自行扩充 |
| `safety/guards.py`、`agent/nodes/output.py` | 提到过敏食材即被误判，连“不要添加”也会降级 | 只识别明确添加指令及未说明避免的食材条目；最终应用正文后再次核对当前禁忌 |
| `agent/answers.py`、`agent/grounding.py` | 相对低脂候选不符合时反复修订；正常无匹配正文因状态变化丢失 | 按已有估算范围预筛候选；无符合结果可正常说明缺口；不虚构替代，不新增低脂或热量阈值 |
| `agent/answers.py`及生成上下文 | 配方原文存在不可靠的鸡肉成熟判断 | 提供已核对的CDC参考，并由程序保留安全提示及来源；正文仍有矛盾，见内容失败 |
| 做法失败路径 | 模型或修订失败后直接重放含可选花生的原文 | 改为简短失败说明，提醒不能未经禁忌核对直接照做，不回放原配方全文 |
| 两个验收脚本及相关夹具 | 用在线审核是否批准作为正常发布条件，部分查询预期不含画像 | 数字/语义反例改显式离线调用；流程验收检查无在线审核、生成次数、画像、来源和最终正文 |

结构化卡片的名称、营养及来源继续从工具事实构建；
最终事实摘要变化使旧正文失效。身份隔离、工具权限、写入确认、
幂等、持久化错误处理和执行预算没有移除。

过敏正文检查有意收窄，代码注明其局限：它不是完整语义分类器，
可能漏掉改写或复杂表达。候选食材安全过滤与这项正文检查是不同层。
移除数字与全文审核也意味着普通正文数值不再有发布前的通用真实性审批。

## 人工内容失败

以下均实际见于v58报告，尚未解决，不能继续声称“已经全部修复”：

- 自然对话“豆腐1盒是多少克”仍回答常见300克、350克等规格；
  过敏用户对应回答虽承认原配方没有克重，也补了无本次产品依据的包装数字。
  原做法重复3次没有新增豆腐克重，不代表该追问已修好。
- 空检索工具条件确为1千卡，正文却写“1000千卡（即1千卡）”，错误来自回答生成。
  本轮没有改变用户实际检索条件，也没有新增600千卡或1000千卡默认值。
- 高蛋白午餐正文把肉蛋盖饭说成候选中“蛋白密度最优”，超出可核实结论；
  换菜、推荐理由和比较仍有健康优势、最优排名或菜品角色的过度推断。
- 凉拌鸡丝先把“筷子轻松插入”当熟度判断，再附温度计安全纠正；
  程序安全提示没有消除这类正文矛盾，不能视为完整食品安全通过。
- 补救回答仍有额外定时、成熟后即可放心食用等过宽断言；
  比较出现内部菜品编号，用量计算也有取整后未联动等内容问题。
- 详细做法仍增加抹油防粘、沥水等配方外操作。共享指令缩短和上下文清理
  改善了部分原请求，但没有可靠地禁止模型扩写。

归因：无在线语义审核、事实数字不再作正文发布门禁是本次Agent设计取舍；
上面的具体错误由模型生成，且系统目前不能普遍识别或保证纠正。
单靠继续加提示词不能宣称解决，当前不恢复导致频繁误拒的审核链路。
后续若做模型对照，需要设计同题实验并记录真实结果；
本次没有更换模型或提供跨模型结论。
