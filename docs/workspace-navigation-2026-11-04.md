# 对话页面布局验收

日期：2026-11-04。

## 改动

原页面将功能导航与历史会话并列放在左边，占用了两列宽度。
本次改为右上角功能菜单、左侧单列会话历史、其余空间展示对话。
保留既有字体、图标和配色，没有增加依赖或服务。

- 移除常驻功能侧栏及重复的手机底部导航，品牌保留在顶部。
- 右上角功能菜单包含对话、饮食偏好、饮食计划、执行记录、质量评估。
  连接状态、重试按钮及连接诊断保留在菜单内。
- 使用 HTML Popover，键盘可打开，Esc、点击外部及选择功能后关闭。
- 桌面历史栏宽260px、位于页面最左侧；较窄视口继续使用左侧历史抽屉。
- 历史搜索、分页、回收站删除/恢复及切换原会话逻辑保持可用。
- Chat组件在切换功能页时继续保留，草稿与后台任务不因导航而重建。
- 精简顶部高度，手机输入区使用底部安全区域，发送按钮触控区域44px。
- 显式约束聊天网格列宽为 `minmax(0, 1fr)`，解决长标题的最小内容宽度
  将输入框和发送按钮挤出320px视口的问题；输入框提示缩短以避免单行截断。
- 更新原浏览器脚本的导航入口及响应式断言，避免继续依赖已删除的侧栏。

## 验证

- 前端 `npm run typecheck`、`npm run build` 通过。
- 五个相关浏览器脚本 Ruff、`mypy --explicit-package-bases` 通过。
- `verify_conversation_trash.py` 使用隔离 Fake API，15项汇总检查通过：
  主流程覆盖1440、390、320，另验证1024、768以及844×390横屏。
- 校验菜单位于右上角、左侧无重复功能侧栏、所有功能可进入、菜单自动关闭、
  键盘打开和Esc恢复焦点、点击外部关闭、无横向溢出及菜单自身不越出视口。
- 校验回收站删除无确认、刷新后可恢复、恢复消息/快照一致、键盘分类切换。
- 生成中跨四个功能页切换后草稿与请求保留，隐藏期间可完成；
  主动停止仍调用取消接口。该部分使用受控SSE，非真实模型验收。
- 在发现页面整体没有溢出但发送按钮仍被裁切后，补充长标题场景下
  工具栏、输入框和发送按钮的实际边界断言，修复后通过。
- 独立执行 `verify_durable_web.py`，真实PostgreSQL、独立Fake Worker、真实SSE
  的桌面/手机10项检查通过：三任务并行/第四个排队、切页/刷新/重开、
  单独停止、离线完成后重连与多标签页观察新轮次。
- 已查看桌面、320手机及844横屏截图，无页面JavaScript错误。
- 输入框短提示及44px手机发送按钮已通过最终构建及同组浏览器复核。
