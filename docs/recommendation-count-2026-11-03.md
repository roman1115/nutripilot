# 回答 Agent 自主表达改造

日期：2026-11-03。状态：已部署到本地真实入口，非真实对话质量验收。

## 已确认问题

- `ground_recommendation_facts` 在构建事实降级正文时，无论有几张卡片，
  都写“可以试试这几道菜”；食材条件分支固定写“这些菜的收录配方都包含”。
  单个命中或仅选中一道时可确定性复现，不是必须调用真实模型才出现的问题。
- 模型自然正文原先没有专门的数量校验；Fake 审核默认同意时，
  单张卡片搭配“这几道菜”的原稿可以通过并在最终输出中发布。
- 推荐理由和普通比较还存在确定性回答快捷路径，会直接跳过回答 Agent。
- 未取得 xerina 所指具体消息的 Trace，因此不能断言那条历史消息实际走的是哪条路径。

## 本轮改动

- 事实降级正文按最终卡片数量使用单复数。
- 移除数量措辞正则和已知主观短语拒绝表，不靠固定字面匹配决定是否通过。
- 推荐理由与比较交由回答 Agent生成；最终推荐卡片、历史展示顺序及来源证据仍进入审核上下文。
- 精简生成、修订和审核提示词，允许自然表达和安全通用烹饪建议；审核聚焦切题、
  对象、来源事实、营养口径、个人/医疗安全与正文推荐对象一致性。
- 保留结构化推荐卡片、事实规范化、数值依据检查、过敏安全、确认和 OutputGuard。
- 不新增服务、依赖、API 字段、迁移或前端改动；提示词版本更新为 `recommendation-v19`。

## 方向讨论

本次方向是由 Agent 根据问题、上下文和证据自主组织正文；程序负责数据契约、
来源和安全边界，不以逐句模板或禁词扩张代替生成。Fake/模型审核都不能证明
真实语言质量，仍需固定真实场景、原始 Trace 与人工正文复核。
